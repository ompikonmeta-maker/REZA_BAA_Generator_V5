BAA.flow — cara pakai untuk Admin & Operator

BAA.flow membantu tim lapangan mengisi Berita Acara (BAA) per lokasi — data, wilayah, inventory, foto, dan scan PDF — lalu mengekspornya ke template Excel/PDF resmi. Pilih panduan sesuai peran Anda.

1.1

Pertama kali membuka aplikasi

Saat aplikasi baru dipasang, admin login dengan akun bawaan lalu langsung diminta mengganti password.

  1. 1Ketik password baru (minimal 4 karakter).
  2. 2Ketik ulang password yang sama.
  3. 3Klik Save & continue.
warning

Password bawaan (admin / admin) diketahui umum. Aplikasi tidak bisa dipakai sebelum diganti.

1.2

Buat project pertama

Satu project = satu pekerjaan BAA dengan template, data, dan tim sendiri.

  1. 1Nama project, mis. Kopdes Merah Putih.
  2. 2Project code (2–4 huruf) — dipakai sebagai awalan kode lokasi, mis. LOK_00001.
  3. 3Warna project — membantu membedakan project di layar.
  4. 4Klik Create & start setup.
lightbulb

Project pertama langsung berisi pengaturan bawaan BAA (4 field, 11 kategori foto, 3 inventory) dan berstatus Setup. Belum ada yang bisa mengisi BAA sampai project diaktifkan.

1.3

Kenali layar utama

Semua menu ada di sidebar kiri. Bagian bawah sidebar selalu terlihat.

  1. 1Pemilih project — pindah project (atau tekan Ctrl+K).
  2. 2Portfolio — ringkasan semua project.
  3. 3BAA Entry — tempat mengisi BAA per lokasi.
  4. 4Location Log — daftar semua lokasi, impor, dan export.
  5. 5Settings — pengaturan project ini dan workspace.
  6. 6Lonceng — permintaan edit dari operator.
  7. 7Timer kerja hari ini.
  8. 8Ganti tema terang / gelap.
1.4

Siapkan project (mode Setup)

Selama Setup, sidebar berubah menjadi langkah-langkah. Kerjakan dari atas ke bawah, lalu aktifkan.

1list_altLocation dataarrow_forward2descriptionTemplate BAAarrow_forward3group_addTeamarrow_forward4eventTarget (opsional)arrow_forward5rocket_launchActivate
  1. 1Langkah setup. Tanda ✓ = selesai, ! = wajib belum selesai.
  2. 2Location data — sudah terisi pengaturan bawaan; status Check sampai Anda mengeceknya.
  3. 3Template BAA — file Excel BAA + pemetaan sel.
  4. 4Team — siapa saja yang boleh masuk.
  5. 5Target — boleh diisi nanti.
  6. 6Activate project aktif setelah semua langkah wajib selesai.
lightbulb

Isi Location data dulu sebelum Template — pemetaan template memerlukan field dan kategori foto.

1.5

Location data · Field lokasi

Tentukan data apa saja yang wajib diisi teknisi untuk setiap lokasi.

  1. 1Isian bawaan sudah ada. Cek ketiga tab dulu.
  2. 2Tiga tab: Location fields, Photos, Inventory. Angka = jumlah isian.
  3. 3Setiap baris = satu field. Nama Lokasi adalah field sistem (terkunci).
  4. 4Quick add — tambah field umum dengan sekali klik.
  5. 5+ Field — buat field sendiri.
  6. 6Sudah sesuai? Klik Looks good — confirm. Langkah ini baru ✓ setelah dikonfirmasi.
lightbulb

Nyalakan Required untuk field yang wajib diisi. Hanya field Required yang dihitung dalam persentase kelengkapan dan wajib terisi sebelum Done; field lain boleh diisi tapi tidak memengaruhi progres.

lightbulb

Pilih Date untuk tanggal. Jangan lupa Save fields bila mengubah sesuatu.

1.6

Location data · Kategori foto

Setiap kategori = satu kotak foto di BAA Entry dan satu gambar di BAA.

  1. 1Tab Photos.
  2. 2Daftar kategori: nama, kata kunci nama file, OCR nomor seri.
  3. 3+ Category untuk menambah.
lightbulb

Kata kunci: foto yang nama filenya mengandung kata ini otomatis masuk kategori tersebut saat upload banyak foto.

lightbulb

Nyalakan OCR untuk foto label SN agar nomor seri terbaca otomatis.

lightbulb

Baris Scan PDF di atas daftar menunjukkan apakah scan PDF wajib di project ini. Ubah lewat Project & status › Features.

1.7

Location data · Inventory

Barang yang dipasang di lokasi (mis. Kit Starlink, Router, Access Point).

  1. 1Tab Inventory.
  2. 2Default items — baris inventory yang otomatis ada di setiap lokasi baru (klik untuk mengatur pilihan Brand / Type).
  3. 3Pilihan Notes (mis. "OK") yang muncul sebagai dropdown di BAA Entry.
1.8

Project berikutnya · pilih isi awal

Untuk project kedua dan seterusnya: Settings › All projects › New project. Pilih dari mana isi awalnya.

  1. 1Start from: Default BAA settings (pengaturan bawaan), Copy from project (salin dari project lain), atau Empty (kosong).
  2. 2Pilih project yang mau disalin.
  3. 3Project code project baru.
  4. 4Simpan — project baru masuk mode Setup.
lightbulb

Bawaan atau salinan tetap harus dicek sekali di langkah Location data (Looks good — confirm).

1.9

Team · Buat akun & beri akses

Buat akun operator langsung dari sini. Akun baru otomatis mendapat akses ke project ini.

  1. 1Isi nama lengkap, username, dan pilih peran (Operator atau Viewer).
  2. 2Klik Add.
  3. 3Password sementara muncul di sini — klik Copy lalu kirim ke orangnya.
  4. 4Nyalakan / matikan akses akun lain ke project ini.
lightbulb

Operator wajib mengganti password sementara saat login pertama.

1.10

Target (opsional)

Jumlah BAA yang harus selesai dan tenggat waktunya. Dipakai untuk menghitung kecepatan di Dashboard dan Progress.

  1. 1Jumlah BAA.
  2. 2Tanggal target.
  3. 3Save target.
1.11

Template BAA

Unggah file Excel BAA, lalu petakan kolom dan sel agar data otomatis masuk saat export.

1upload_fileUpload templatearrow_forward2table_rowsPetakan Log Sheetarrow_forward3grid_onPetakan Detail Sheetarrow_forward4saveSave mapping
  1. 1Template yang sedang aktif.
  2. 2Upload template — pilih file .xlsx.
  3. 3Langkah 1: pilih template & sheet.
  4. 4Langkah 2: Log Sheet — tabel daftar lokasi.
  5. 5Langkah 3: Detail Sheet — halaman BAA per lokasi (data, inventory, foto).
  6. 6Save mapping setelah selesai.
1.12

Template BAA · Memetakan kolom

Untuk setiap judul kolom di Excel, pilih data aplikasi yang akan mengisinya.

  1. 1Langkah yang sedang dibuka.
  2. 2Pilih isi kolom dari daftar (Data, Wilayah, Inventory, Foto).
  3. 3Persentase pemetaan yang sudah lengkap.
  4. 4Save mapping.
lightbulb

Lupa menyimpan? Saat pindah menu, aplikasi akan bertanya Save / Discard.

1.13

Dashboard admin

Ringkasan harian: capaian tim, kecepatan, dan siapa yang perlu dibantu.

  1. 1Info cepat (mis. jumlah lokasi yang menunggu diselesaikan).
  2. 2Capaian vs target, kecepatan yang dibutuhkan, dan tanggal target.
  3. 3Tabel tim: online/tidak, draf terbuka, umur draf.
1.14

Progress & peta wilayah

Lihat sebaran lokasi per wilayah dan prakiraan capaian target.

  1. 1Peta per kabupaten/kota — klik baris untuk memperbesar.
lightbulb

Klik ikon pensil di angka target / tanggal untuk mengubahnya langsung.

1.15

Portfolio (banyak project)

Satu kartu per project. Klik kartu untuk membuka project itu.

  1. 1Total semua project.
  2. 2Kartu project: persentase, status kecepatan, draf terbuka.
  3. 3Peta mini sebaran lokasi.
1.16

Location Log

Daftar semua lokasi. Cari, saring, export, impor, dan pulihkan lokasi yang terhapus.

  1. 1Active / Deleted — lihat lokasi yang terhapus dan pulihkan.
  2. 2Import locations dari Excel.
  3. 3Cari kode atau nama lokasi.
  4. 4Saring berdasarkan pembuat.
  5. 5Saring berdasarkan wilayah.
  6. 6Export banyak lokasi sekaligus (Excel / PDF per lokasi).
  7. 7Centang beberapa lokasi untuk aksi massal (mis. isi wilayah).
lightbulb

Klik baris lokasi untuk membuka panel detail di kanan.

1.17

Panel detail lokasi

Cek kelengkapan satu lokasi tanpa membuka BAA Entry.

  1. 1Persentase kelengkapan lokasi.
  2. 2Foto yang sudah ada (klik untuk melihat di BAA Entry).
  3. 3Status Scan PDF — klik Open untuk membuka.
  4. 4Perangkat terpasang dan nomor serinya.
  5. 5Edit in BAA Entry.
1.18

Import lokasi dari Excel

Masukkan banyak lokasi sekaligus. Kode lokasi dibuat otomatis.

1downloadDownload templatearrow_forward2edit_noteIsi di Excelarrow_forward3upload_fileUploadarrow_forward4previewCek previewarrow_forward5done_allImport
  1. 1Ikuti 4 langkah di kiri.
  2. 2Download Template — format Excel yang benar.
  3. 3Klik untuk memilih file yang sudah diisi.
  4. 4Klik Import setelah preview benar.
1.19

Permintaan edit (lonceng)

Operator hanya bisa mengubah lokasi miliknya. Jika perlu mengubah lokasi orang lain, ia mengirim permintaan.

  1. 1Lokasi, peminta, dan pemilik saat ini.
  2. 2Approve — lokasi pindah ke peminta.
  3. 3Angka merah di lonceng = jumlah permintaan baru.
lightbulb

Tombol ✕ untuk menolak permintaan.

1.20

Lokasi terhapus

Lokasi yang dihapus tidak langsung hilang. Data dan foto tetap tersimpan.

  1. 1Tab Deleted di Location Log.
  2. 2Pulihkan atau hapus permanen dari sini.
1.21

Project & status

Ubah nama, warna, target, fitur Wilayah, dan akses. Di sini juga Freeze / Unfreeze.

  1. 1Status project: SETUP, ACTIVE, atau FROZEN.
  2. 2Freeze — hentikan semua input sementara.
  3. 3Project code terkunci setelah kode lokasi pertama terbit.
  4. 4Target BAA dan tanggal.
  5. 5Features: Wilayah data (dan apakah dihitung dalam kelengkapan) serta Scan PDF required.
lightbulb

Ada perubahan yang belum disimpan? Indikator Unsaved muncul di kanan atas dan aplikasi mengingatkan sebelum pindah menu.

1.22

Freeze project

Bekukan project saat admin perlu merapikan sesuatu (mis. revisi template). Operator hanya bisa melihat.

  1. 1Tulis pesan untuk tim.
  2. 2Atau pilih pesan cepat.
  3. 3Pratinjau banner yang dilihat tim.
  4. 4Freeze project.
warning

Saat Frozen, operator tidak bisa mengisi, mengubah, upload, impor, maupun export.

1.23

Saat project Frozen

Admin tetap bisa mengubah pengaturan dan data. Banner biru muncul di semua halaman.

  1. 1Banner pesan untuk semua user.
  2. 2Status FROZEN.
  3. 3Edit message — ubah pesan.
  4. 4Unfreeze — buka kembali input.
  5. 5Change project code… — ganti project code (hanya saat Frozen).
1.24

Ganti project code

Mengubah semua kode, mis. LOK_00001 → KMP_00001. Nomor tetap sama; folder foto & scan ikut pindah.

  1. 1Ketik project code baru, klik Analyse.
  2. 2Ringkasan yang akan berubah.
  3. 3Contoh kode lama → baru.
  4. 4Re-code untuk menerapkan.
lightbulb

Kode lama tetap bisa dicari di Location Log.

warning

File PDF/Excel yang sudah pernah dikirim tetap memakai kode lama.

1.25

Users

Kelola semua akun di seluruh project.

  1. 1Username untuk login.
  2. 2Peran: Operator (isi BAA), Viewer (lihat saja), Admin.
  3. 3Project yang boleh dibuka.
  4. 4Save.
lightbulb

Mengisi password baru untuk user lama = reset password. User wajib menggantinya saat login berikutnya.

1.26

Backup & Restore

Simpan cadangan seluruh data secara rutin.

  1. 1Download backup — satu file berisi semua data & foto.
  2. 2Pulihkan dari file backup.
lightbulb

Foto baru otomatis dikecilkan saat upload (maks. 2000 px) agar folder data tidak cepat penuh — tanggal & GPS kamera tetap tersimpan, hasil export BAA tetap sama.

lightbulb

Compress existing photos — kecilkan foto lama sekali jalan. Download backup dulu bila ingin menyimpan file aslinya.

warning

Restore mengganti seluruh data saat ini dengan isi file backup.

2.1

Login pertama

Admin memberi username dan password sementara. Saat login pertama, ganti dengan password sendiri.

  1. 1Password baru (minimal 4 karakter).
  2. 2Ulangi password baru.
  3. 3Save & continue.
lightbulb

Lupa password? Minta admin membuat password sementara baru.

2.2

Dashboard saya

Lihat target minggu ini dan draf yang perlu diselesaikan.

  1. 1New location — mulai BAA baru.
  2. 2Continue — lanjutkan draf yang paling hampir selesai.
  3. 3Target pribadi minggu ini.
  4. 4Draf saya: persentase, yang masih kurang, dan umur draf. Klik Open.
lightbulb

Chip kuning/oranye menunjukkan apa yang masih kurang, mis. Scan PDF atau 2 photos.

2.3

BAA Entry · Data lokasi

Satu halaman untuk satu lokasi. Ringkasan di kanan menunjukkan apa yang masih kurang.

  1. 1Pilih lokasi yang mau diisi.
  2. 2Add Location — buat lokasi baru (kode dibuat otomatis).
  3. 3Isi data lokasi. Tanda * = wajib.
  4. 4Wilayah: desa, kecamatan, kab/kota, provinsi.
  5. 5BAA Summary — persentase dan daftar kekurangan.
  6. 6Finish BAA — tandai selesai (Done) bila sudah 100%.
  7. 7Saved — isian draft tersimpan otomatis saat Anda mengetik.
2.4

Mengisi wilayah dengan cepat

Ketik nama desa ditambah kata lain (kecamatan / kabupaten) — urutan bebas, boleh salah ketik sedikit.

  1. 1Ketik mis. cibodas lembang.
  2. 2Pilih hasil yang benar — keempat tingkat terisi sekaligus.
  3. 3Desa tidak ada di daftar? Isi manual sesuai tulisan teknisi.
2.5

Inventory

Perangkat yang dipasang: jenis, jumlah, nomor seri (SN), dan keterangan.

  1. 1Isi setiap baris. SN bisa terisi otomatis dari foto label (OCR).
lightbulb

Brand/Type dan Notes punya pilihan yang muncul saat mengetik.

2.6

Foto

Seret banyak foto sekaligus — aplikasi memasukkan ke kategori yang cocok berdasarkan nama file.

  1. 1Upload — pilih banyak foto sekaligus (atau seret ke area ini).
  2. 2Clear all — hapus semua foto lokasi ini.
  3. 3Jumlah kategori yang sudah terisi.
  4. 4Kotak per kategori. Klik kotak untuk mengganti, mengedit, atau mengisi SN manual.
lightbulb

Beri nama file sesuai kategori (mis. depan.jpg, sn_router.jpg) agar otomatis masuk kotak yang benar.

2.7

Scan PDF

Dokumen BAA bertanda tangan yang sudah discan. Wajib untuk setiap lokasi.

  1. 1Klik atau seret file .pdf ke sini (maks. 25 MB).
  2. 2Label Required berubah hijau setelah diupload.
lightbulb

Scan PDF menjadi halaman pertama saat export PDF.

2.8

Simpan & selesai

Draft tersimpan otomatis. Saat persentase 100%, klik Finish BAA agar lokasi berstatus Done.

  1. 1Persentase kelengkapan.
  2. 2Baris hijau = sudah lengkap.
  3. 3Baris merah = masih kurang.
  4. 4Keterangan apa saja yang masih kurang sebelum bisa Done.
  5. 5Finish BAA — angka N left = jumlah bagian yang masih kurang. Aktif penuh di 100%.
  6. 6Export PDF lokasi ini — langsung terunduh.
  7. 7Export Excel lokasi ini — langsung terunduh.
lightbulb

Tidak perlu klik simpan untuk draft: indikator Saving… → Saved di bar atas menandakan isian sudah tersimpan.

lightbulb

Setelah Finish, muncul Next draft — klik Open untuk lanjut ke draf berikutnya.

lightbulb

Lokasi yang sudah Done diubah lewat Save changes; bila jadi tidak lengkap, statusnya kembali Draft.

2.9

Location Log

Daftar semua lokasi. Semua orang bisa melihat semua lokasi.

  1. 1Cari kode atau nama.
  2. 2Saring All / Draft / Done.
  3. 3Klik baris untuk membuka panel detail.
  4. 4Export banyak lokasi sekaligus.
2.10

Lengkapi dari panel detail

Upload foto yang kurang dan scan PDF langsung dari panel, tanpa membuka BAA Entry.

  1. 1Kotak putus-putus = foto yang belum ada.
  2. 2Klik kotak → pilih foto → Save.
  3. 3Scan PDF: klik Upload.
  4. 4Edit in BAA Entry untuk mengubah yang lain.
2.11

Lokasi milik orang lain

Lokasi orang lain hanya bisa dilihat (Read Only). Untuk mengubahnya, minta akses ke admin.

  1. 1Tanda Read Only.
  2. 2Request edit — setelah admin menyetujui, lokasi pindah menjadi milik Anda.
2.12

Export

Buat file Excel BAA atau PDF untuk dikirim.

  1. 1Lokasi sesuai saringan yang sedang aktif.
  2. 2Atau semua lokasi.
  3. 3Create — file disiapkan lalu diunduh.
2.13

Saat project dibekukan (Frozen)

Admin sedang merapikan sesuatu. Anda tetap bisa melihat data, tetapi belum bisa mengisi atau mengubah.

  1. 1Pesan dari admin dan sejak kapan dibekukan.
lightbulb

Tunggu sampai admin membuka kembali (Unfreeze). Data yang sudah tersimpan aman.
