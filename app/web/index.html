How to read the Supervisor Console
Green — On-track. Velocity steady/rising, no stalled drafts.
Yellow — Slowing. Fewer locations done this week than last week.
Red — Declining/stalled. Sharp drop (>40%), 0 done this week, or ≥3 stalled drafts.

Velocity = number of locations completed per week. The big number + ▲/▼ compares to last week.

Cycle time = average days a location takes from created to done. Smaller is faster.

Stalled draft = an unfinished location untouched for > 7 days.

Workload = number of active drafts a user owns (a longer, redder bar = more held up).

Bottleneck = what most often keeps a location unfinished (e.g. SN photos or inventory), as a % of all drafts.

Ranking is sorted by highest completion %. Click a user row to see the locations holding them back.
